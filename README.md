# Linux Security Dashboard


A locally hosted security monitoring dashboard built with  Apache, MySQL, and Bash scripting on Ubuntu Linux.


## Features
-Live system health monitoring 
-Failed login attempt tracking
-User and privilege auditing
-MySQL-backed logging


## Stack
-Apache2 (web server)
-MariaDB/MySQL (database)
-Bash (backend scripts)
-HTML/CSS (frrontend)


## Setup
'''bash
git clone https://github.com/turgunovyosinbek09-cloud/linux-security-dashboard
cd linux-security-dashboard
chmod +x setup.sh
sudo ./setup.sh
'''
